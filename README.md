# 📜 LegitAI - AI-Powered Legal Contract Analyzer 🚀

LegitAI is an AI-powered tool that analyzes legal contracts using NLP and GPT-4.

## Features
✅ AI-Powered Clause Extraction (LAW, ORG, DATE, MONEY, GPE)  
✅ Instant Contract Summaries  
✅ User-Friendly Interface  

## Installation & Setup
1️⃣ Clone the repository:  
   ```sh
   git clone https://github.com/your-username/LegitAI.git
   cd LegitAI
   ```

2️⃣ Install dependencies:  
   ```sh
   pip install -r requirements.txt
   ```

3️⃣ Secure your API Key:  
   - Copy `.env.example` to `.env`:  
     ```sh
     cp .env.example .env
     ```
   - Add your OpenAI API key inside `.env`.

4️⃣ Run the Backend (Flask API):  
   ```sh
   python backend/app.py
   ```

5️⃣ Run the Frontend (Streamlit UI):  
   ```sh
   streamlit run frontend/frontend.py
   ```
